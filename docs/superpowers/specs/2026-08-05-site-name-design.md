# 网站名称调整设计

## 目标

将面向用户的网站名称统一为“周三充值日拼图互助”，让浏览器标题、首页和项目说明使用同一品牌名称。

## 范围

- 将 Next.js 页面元数据标题改为“周三充值日拼图互助”。
- 将元数据描述改为“周三充值日拼图互助大厅”。
- 将首页主标题改为“周三充值日拼图互助”。
- 将 README 标题、项目简介和部署指南中的旧网站名称替换为新名称。
- 为浏览器元数据和首页主标题补充自动化测试。

## 不在范围内

- 不修改 GitHub 仓库名、仓库 URL、本地目录名或 npm 包名 `cmcc-puzzle-hub`。
- 不修改 Vercel 项目名、Upstash 数据库名等技术标识。
- 不修改“大厅”“发布拼图”等功能名称。
- 不调整现有页面布局、导航、业务流程或数据结构。

## 验收标准

1. 浏览器标题显示“周三充值日拼图互助”。
2. 首页首个一级标题显示“周三充值日拼图互助”。
3. README 和部署指南不再把旧名称“中国移动拼图互助平台”作为网站名称。
4. 仓库、包和部署相关技术标识仍为 `cmcc-puzzle-hub`。
5. 名称相关测试、lint、类型检查、单元测试和生产构建通过。
